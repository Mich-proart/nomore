Este bloqueador funciona a través de dos métodos:

1. Edición del archivo HOSTS de Windows para bloquear sitios web conocidos por contenido explícito.
2. Configuración automática de DNS con filtros de contenido usando CleanBrowsing.

--- USO ---

1. Haz clic derecho en `bloquear_porno.bat` y selecciona "Ejecutar como administrador".
2. Esto bloqueará miles de dominios pornográficos y establecerá los DNS de CleanBrowsing.
3. Puedes revertir el bloqueo con `desbloquear_porno.bat`.

IMPORTANTE: Ejecuta estos archivos como ADMINISTRADOR.
